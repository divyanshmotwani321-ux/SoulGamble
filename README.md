```markdown
# Soul Gamble: The D'Arby Showdown 🃏

A 90s arcade-style, FPV 5-Card Draw Poker simulator based on *JoJo's Bizarre Adventure*. Built as a Data Structures lab project, this game replaces flat randomized arrays with real-time inspectable data structures (Deque, LIFO Stack, Hash Maps, and Finite State Machines) to simulate psychological warfare, sleight-of-hand cheats, and high-stakes soul gambling.

## 🚀 How to Play on Your Local Machine

Follow these steps to fetch the project and run it locally on your computer:
```

### 1. Clone the Repository
Open your terminal or command prompt and fetch the repository:
```bash
git clone https://github.com/divyanshmotwani321-ux/SoulGamble.git

```

### 2. Open in Your Code Editor

Navigate into the downloaded project folder and open it in your preferred code editor (like **VS Code** or **Antigravity**).

### 3. Install Dependencies

Open the terminal inside your code editor and run this command to install the required packages:

```bash
npm install

```

### 4. Build and Run the Game

Once the setup is done, build the project and start the local server by running these two commands:

```bash
npm run build
npm run dev

```

### 5. Launch in Browser

After running the dev command, your terminal will display a local server link (usually something like `http://localhost:5173` or `http://localhost:3000`).

* Copy that localhost link.
* Paste it into your web browser.
* Start playing!
